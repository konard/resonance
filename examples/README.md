# Examples

This directory contains example implementations and demos for the Resonance project.

## WebRTC Demo

`webrtc-demo.html` - A standalone HTML file demonstrating WebRTC peer connection setup and data channel communication.

**To run:**
1. Open the file directly in a web browser
2. Click "Create Connection" to see how peer connections are established
3. Monitor the log for connection events and messages

This demonstrates the core technology that will be used to sync audio playback across multiple devices.

## Usage

These examples serve as:
- Reference implementations for core features
- Testing utilities for WebRTC functionality
- Educational resources for understanding the sync mechanism
