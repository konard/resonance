# Resonance

A cross-platform application for playing music across your devices in sync - use all their speakers at once!

## Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

Visit [http://localhost:3000](http://localhost:3000) to see the app.

## What is this?

This is a **proof of concept** implementation using the "repository that rules them all" approach - a single codebase that can be deployed to:

- 🌐 **Web** (Progressive Web App)
- 📱 **iOS** (via Capacitor)
- 🤖 **Android** (via Capacitor)
- 💻 **Desktop** (via Electron - planned)

## Technology

- **Next.js** + **React** + **TypeScript**
- **Tailwind CSS** for styling
- **Capacitor** for mobile platforms
- **WebRTC** for device-to-device communication

## Features

✅ Responsive web application
✅ Cross-platform foundation (Web, iOS, Android)
✅ WebRTC setup for peer-to-peer sync
✅ Music player UI
✅ Device connection management
